The robot needs no printed markers: the phone mounted on the Cutebot is the only camera, and nothing watches
the table from above (T111). Build instructions: `docs/build.md`.

Compute and video run on the laptop and mounted phone. No NVIDIA Jetson, Arduino, USB camera,
Raspberry Pi 5, debug probe or crocodile clips are needed. See the active parts list in
[the build guide](../docs/build.md) and [phone setup](../docs/network.md#4-start-and-check-every-link).
